## 若要收紧，正确动作是什么（写进 spec 供下次引用）

**授 / 收权限码**，不要加 role 判定：权限码是授权 SSOT（ADR-051 §决策 2），角色树可勾选 = 绑定 code（ADR-056）。给某用户多一个 `doc.upload` 是「授权」；按 `kb_members.role` 判能不能写是**改冻结语义**。
