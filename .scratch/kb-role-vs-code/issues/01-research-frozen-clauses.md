Type: research
Status: resolved
Blocked by: 无

## 问题

`prds/00–11` 里所有把 `kb_members.role` / 「read 能做什么」当**授权判据**的条款，逐条列出并判定是否被后续 ADR **点名**修订；同时列出「以权限码为准」一侧。

**「点名」判定口径**：后续 ADR 的**状态行 / 修订关系 / 后果**段明确写出被修订的 ADR 编号或条款名（如「修订 ADR-045 壳准入」）。**无此写法即记「未销账」**，不因版本更晚推断取代。

### 四、文本内**唯一**的明文冲突裁决序（本席已亲自复核原文）
