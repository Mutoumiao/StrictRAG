# @strict-rag/eslint-config

共享 ESLint flat config。

| 导出 | 用途 |
|------|------|
| `@strict-rag/eslint-config/base` | Node / 共享包 |
| `@strict-rag/eslint-config/next-js` | `apps/admin` · `apps/web` |
| `@strict-rag/eslint-config/react-internal` | `packages/ui` |

```js
// eslint.config.js
import { config } from '@strict-rag/eslint-config/base';
export default config;
```
