## 4. 全局 UI 状态规格（空 · 载 · 错 · 权限）

> 原则：**任何数据驱动面**必须可落到下列状态之一；禁止白屏、禁止静默失败。

### 4.1 通用状态机

```text
idle → loading → { empty | success | error | forbidden }
                    └─ 可重试的 error ──► loading
```

| 状态 | 用户感知 | 设计要求 |
|------|----------|----------|
| **loading** | 正在处理 | 骨架屏或行级 spinner；问答用流式占位；**超时有文案** |
| **empty** | 合法地没有数据 | 说明原因 + **一个主行动**（新建/上传/联系管理员） |
| **error** | 请求失败 / 系统故障 | 人话说明 + 重试；不把堆栈给业务用户 |
| **forbidden** | 无权限 | 说明「无权限」+ 找谁；**不要**只藏按钮却直链可进半截页 |
| **success** | 有数据 | 主列表/主内容 |

### 4.2 分屏必达状态（P2）

| 屏 | loading | empty | error | forbidden / 特殊 |
|----|---------|-------|-------|------------------|
| web 会话列表 | 列表骨架 | 「还没有会话」+ [新建会话] | 重试拉列表 | — |
| web 聊天区 | 历史骨架；发送后「生成中」流式 | 新会话欢迎语 + 示例问法（非幻觉承诺） | 发送失败可重试；**拒答是 success 业务态**不是 error | 无 KB 权限：引导换库/联系管理员 |
| web 无可用库 | — | 「你还没有可提问的知识库」 | — | 主行动：联系管理员 |
| admin 文档列表 | 表骨架 | 「还没有文档」+ [上传] | 重试 | 无 `doc.view`：整页 403 态 |
| admin 审批 | 表骨架 | 「暂无待审」 | 重试 | 无 `approval.decide`：无通过/驳回按钮 |
| admin 分片 | 表骨架 | 先选文档 / 该文档无分片 | 重试 | 无 `chunk.view` |
| admin 反馈 | 表骨架 | 「暂无反馈」 | 重试 | 无队列码 |
| admin 成员 | 表骨架 | 「仅自己或空」+ [邀请] | 重试 | 无 `member.manage` |
| 上传 / complete | 上传进度 | — | 超限/类型不支持/杀毒失败说明 | — |
| 入库进度 | 状态列：处理中… | — | failed / needs_ocr 标签 | 待审不可当「卡住」误导 |

### 4.3 问答结果态（勿与 HTTP 错误混淆）

| 结果 | UI 归类 | 说明 |
|------|---------|------|
| `answered` + knowledge | 成功内容 | 正文 + 引用 + 反馈 |
| `answered` + chitchat | 成功轻内容 | **无**知识库引用区 |
| `abstained` + reason | **正式业务结果** | reason 映射 + 建议动作；HTTP 200 |
| 401/403/429/5xx | 系统/权限错误 | 走 error/forbidden 组件，不是拒答卡片 |
| `SESSION_REWRITE_DISABLED` | 配置/能力错误 | **不得**文案写成「会话功能不可用」 |

### 4.4 文案禁忌（全局）

- 不写「AI 一定会答对」  
- 不写 P2「支持连续追问 / 上下文记忆当制度」  
- 不写「部门已完全隔离」若未开 `DEPT_ACL_ENFORCE`  
- 拒答区避免「系统错误」语气（除非 `internal_guard`）
